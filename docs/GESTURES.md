# Supported gesture vocabulary

> Generated by `npm run docs:gestures` from `packages/shared/gestures.js`. Do not edit by hand.

Application-defined hand poses chosen to be easy for a camera to separate. They are NOT validated signs of Indian Sign Language, ASL or any other sign language, and the phrases are classroom conventions.

**Clarity** is a geometric margin (distance of each measurement from its decision threshold). It is not a probability and is shown to students only as "clear" / "borderline".

Thresholds: `{"finger":1.5,"fingerBand":0.35,"thumb":0.62,"thumbBand":0.25,"pinch":0.38,"pinchBand":0.2,"thumbVertical":0.5,"minPalm":0.04}`
